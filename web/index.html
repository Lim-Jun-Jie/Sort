How the sorting interface works

Implement std::vector<int> mySort(std::vector<int> unsorted) and make the Function name field match. Sort the vector and return it. For example, include <algorithm> and call std::sort(unsorted.begin(), unsorted.end()). When your function returns, its resulting vector is replayed as writes in the visualization.
