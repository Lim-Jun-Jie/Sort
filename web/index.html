How the sorting interface works

Implement vector<int> mySort(vector<int> unsorted); use the Function name field for your function's name, and return the sorted vector. Include "sort_helpers.hpp" for optional playback helpers: sortviz::compare(unsorted, i, j), sortviz::swap(unsorted, i, j), sortviz::write(unsorted, i, value), and sortviz::markSorted(i). These helpers show each operation during playback. You can also use regular vector operations and the C++ standard library; uninstrumented changes are shown as final writes.
